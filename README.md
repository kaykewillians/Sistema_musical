# Sistema_musical

## Sobre o projeto

O Sistema Musical é um projeto desenvolvido com o objetivo de organizar e facilitar o gerenciamento de artistas e músicas por meio de uma interface simples e intuitiva.

O sistema permite visualizar artistas cadastrados, organizar informações musicais e navegar entre diferentes páginas de gerenciamento.

O projeto foi desenvolvido utilizando HTML e CSS, aplicando conceitos de estruturação de páginas, estilização, formulários e tabelas.

## Funcionalidades

Cadastro de artistas.

Cadastro de músicas.

Biblioteca musical.

Listagem de músicas cadastradas.

Exibição de informações dos artistas.

Adição de fotos de artistas e capas de músicas.

Opções de edição e exclusão.

Navegação entre as páginas do sistema.

Interface adaptável para dispositivos móveis.

## Identidade visual

O sistema utiliza uma identidade visual baseada em tons de azul, buscando transmitir organização, simplicidade e facilidade de utilização.

As principais cores utilizadas são:

Azul escuro: #2c3e50

Azul principal: #3498db

Verde: #27ae60

Vermelho: #e74c3c

Fundo: #f0f2f5

## Como executar o projeto

Abra a pasta do projeto no Visual Studio Code.

Localize o arquivo login.html ou index.html.

Clique com o botão direito sobre o arquivo.

Selecione a opção Open with Live Server.

O sistema será aberto automaticamente no navegador.
